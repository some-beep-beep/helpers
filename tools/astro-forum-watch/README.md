# astro-forum-watch — новые объявления с Астрофорума в Telegram

Каждые ~5 минут GitHub Actions открывает раздел [«Доска объявлений»](https://astronomy.ru/forum/index.php/board,35.0.html), находит новые темы и присылает каждую в Telegram: название, автор, время, цена (если нашлась), начало текста и ссылка. Объявления про **моно-камеру на Sony IMX533**, **электронное колесо фильтров (7–8 позиций)** и **Sharpstar 61 EDPH II/III** помечаются (комплекты из нескольких предметов приходят одним сообщением с 📦):
- **🎯 НАЙДЕНО** (счёт ≥ 10): точная модель моно (ZWO ASI533MM, Player One Ares-M, QHY533M, ToupTek ATR533M, Altair Hypercam 533M, Omegon 533M);
- **🔎 Проверь вручную** (счёт 4–9): возможное совпадение (IMX533 + «моно», «533» + «камера/охлажд», asi533/qhy533 без суффикса M/C, Svbony на 533);
- без пометки: остальные объявления (можно выключить, см. `post_all`).

## Как это работает

- Одна страница раздела (≈70 КБ) + по одному запросу на каждое **новое** объявление (текст первого сообщения). Между запросами пауза 3 секунды, как просит `robots.txt` форума (`Crawl-delay: 3`). Страница раздела не запрещена в `robots.txt`.
- Какие темы уже отправлены, хранится в листе `ForumSeen` (Google Sheets). Новая тема = её id нет в листе.
- Первый запуск ничего не присылает из старого: он запоминает всё, что сейчас на доске, и пишет одно сообщение «слежение запущено».
- Если Telegram не принял сообщение, тема не помечается увиденной и придёт в следующий запуск.
- Новые темы приходят от старых к новым, но не больше 15 за запуск.

## Скорость

GitHub Actions ставит расписание не чаще раза в 5 минут, и запуск может опаздывать на несколько минут (иногда больше при нагрузке GitHub). Реальная задержка до сообщения обычно 5–15 минут. Если нужно быстрее, можно запускать тот же скрипт триггером Google Apps Script каждую минуту или на домашнем компьютере/малине по cron.

## Настройка (один раз)

### 1. Telegram
Нужен бот и чат/канал, куда писать. Можно использовать уже созданного бота `@w_t_tickets_bot` и свой личный чат (тогда новых секретов для Telegram не нужно: используются `TG_BOT_TOKEN` и `TG_CHAT_ID`).
Если нужен отдельный канал или бот, создайте их (бот: `@BotFather` → `/newbot`; в канале бот должен быть администратором с правом публикации) и добавьте секреты `FORUM_TG_BOT_TOKEN` и `FORUM_TG_CHAT_ID`. Они имеют приоритет над `TG_*`.

### 2. Google Sheets (обновить Apps Script)
1. Вставьте новый `apps-script/Code.gs` в проект `helpers-finance API`.
2. **Deploy → Manage deployments → ✏️ Edit → New version → Deploy.** Не создавайте New deployment: URL должен остаться прежним.
3. Лист `ForumSeen` создастся сам при первой записи.

### 3. GitHub Secrets
Уже есть, если настроен RA-check: `SHEETS_API_URL`, `SHEETS_API_TOKEN`, `TG_BOT_TOKEN`, `TG_CHAT_ID`.
Для отдельного канала или бота добавить: `FORUM_TG_BOT_TOKEN`, `FORUM_TG_CHAT_ID`.

### 4. Первый запуск
Repo → Actions → **Astro forum watch** → **Run workflow**. В Telegram придёт сообщение «слежение запущено», в листе появятся текущие темы. Дальше работает само.

## Локально

```bash
python3 tools/astro-forum-watch/watch.py --dry-run
```
Без Telegram и без записи: покажет три самые свежие темы так, как они придут в канал.

## Как работает матчинг (`match.py`)

Три независимых правила, у каждого свой скоринг и свои пометки. Если в одном объявлении совпали два правила и больше (комплект), в начале сообщения добавляется **📦 КОМПЛЕКТ, высокий приоритет**.

**Общая нормализация.** Нижний регистр; кириллические алиасы брендов (зво, асай/аси, плеер ван, куэйчайвай, тоуптек, альтаир, омегон, шарпстар/шарп стар/sharp star); кириллические омоглифы → латиница (а→a, с→c, м→m, е→e, о→o, р→p, т→t, х→x, в→b, к→k, н→h); без дефисов, точек и лишних пробелов. Римские цифры после «61edph» приводятся к виду: `lll/iii/Ⅲ/3/mk3 → 3`, `ll/ii/Ⅱ/2/mk2 → 2`.

**Схема счёта (для каждого правила).** Тир A (точное совпадение) +10; тир B («проверь вручную») +4, не выше 9; бонусы начисляются только при совпадении A или B; исключение без явного A даёт −10. Уровни: ≥ 10 — 🎯 НАЙДЕНО, 4–9 — 🔎 Проверь вручную, иначе без пометки.

### 1. Камера на IMX533 (`camera`)
- **A:** ZWO ASI533MM, Player One Ares-M, QHY533M (не MC), ToupTek ATR533M, Altair Hypercam 533M, Omegon 533M.
- **B:** IMX533 + «моно»; «533» + «камера/охлажд» без цветных признаков; asi533/qhy533 без суффикса M/C; Svbony на 533.
- **Исключения:** цветные (`533mc`, `ares c`, `atr533c`, `hypercam 533c`, color/цветн/osc/one shot) и другие модели ASI (585/294/183/071/2600/2400/1600/178/174). Если рядом и моно, и исключение (например «меняю MC на MM»), объявление не отбрасывается, а помечается ⚠️.
- **Бонусы:** +4 pro/cooled/охлажд, +3 колесо/efw/фильтры/комплект, +2 цена в диапазоне.

### 2. Электронное колесо фильтров, 7 или 8 позиций (`wheel`)
- **A:** ZWO EFW 7x36 и 8x31/8x1.25"; QHY CFW3 (M-US = 7x36, S = 7 поз. 1.25"/31 мм, L = 7x2"); Player One **Phoenix Wheel**; Atik EFW2; ToupTek **AFW** 7x36; колёса ToupTek/Altair/Svbony.
- **B:** EFW без размера, CFW2/CFW3 без уточнения, «электронное колесо», «7–8 позиций + колесо».
- **Исключения (−10):** ручные (manual/ручн/mechanical); 5 позиций и меньше (`5x`, `5 pos`, `mini`: EFW mini 5x1.25"); QHY CFW3M-US5, S-US6, M-SR (5–6 позиций, 2"). «Просто фильтры» без колеса колесом не считаются.
- **Бонусы:** +5 фильтры в комплекте (lrgb, ha, oiii, sii, astronomik, baader, antlia, optolong, фильтры ZWO), +3 если рядом найдена камера на 533, +2 цена.

### 3. Телескоп Sharpstar 61 EDPH II / III (`scope`)
- **A:** 61EDPH II или III в любом написании (`ll`, `ii`, `Ⅱ`, `2`, `mk2`, `lll`, `iii`, `3`, `mk3`, «61 ed ph»), бренд необязателен.
- **B:** 61EDPH без номера (возможно первая версия, уточнить у продавца); Sharpstar + «61 мм рефрактор/apo/ed».
- **Исключения (−10):** другие Sharpstar (76/94/120 EDPH, 15028, 13028, HNT, 130); только аксессуары (сумка, кейс, кольца, ссылка) без слова телескоп/труба/рефрактор.
- **Бонусы:** +4 редуктор, корректор, кольца; +2 цена.

**Проданное** (`продано|продан|sold|закрыт|в резерве` в названии темы) пропускается. **Цена** берётся из текста осторожно и только подсказка: объявления без цены не отбрасываются.

## Настройка под себя (`config.json`)

- `post_all` — слать все новые объявления (`true`) или только 🎯 и 🔎 (`false`). Остальные в этом случае просто запоминаются.
- `skip_sold` — пропускать темы с «Продано/в резерве/закрыто» в названии.
- `rules.camera|wheel|scope` — для каждого правила: `enabled` (включить/выключить) и `price_min`, `price_max` (диапазон цены в рублях для бонуса +2, `null` — без бонуса). Объявления без цены не отбрасываются.
- `snippet_chars` — сколько символов текста показывать.
- `max_per_run`, `keep_rows` — лимиты сообщений за запуск и размер истории в листе.

## Заметки

- Присылаются все новые темы раздела (кроме проданных), матчинг только помечает совпадения.
- Пока не реализовано: слежение за изменением цены/текста уже виденных объявлений.
- Если форум изменит разметку и скрипт не найдёт ни одной темы, запуск завершится ошибкой (GitHub пришлёт письмо о падении workflow).
- Если в течение 60 дней в репозитории нет активности, GitHub отключает запуски по расписанию; включите workflow вручную.
