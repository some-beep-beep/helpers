# Утренний дайджест портфеля в Telegram

Статус: **задумано, ещё не реализовано**  
Дата фиксации: 2026-10-30  
Контекст: личный портфель `helpers` (Invest / Google Sheets / Apps Script)

## Зачем

Каждый день в **08:00 по Минску** (`Europe/Minsk`, UTC+3) получать в Telegram краткий статус портфеля — только себе, для статистики. Не публичный канал для аудитории.

Куда слать (на выбор при внедрении):

- **приватный канал** только для себя, или
- **личные сообщения** бота (ещё проще: канал не нужен)

## Что должно быть в сообщении

Короткий текст, без картинок на первом этапе:

1. **Всего Invest** — текущая стоимость позиций без НЗ  
2. **Все сбережения** — Invest + НЗ  
3. **± по категориям** (сумма сейчас и результат, где есть смысл):
   - облигации  
   - токены  
   - вклады  
   - золото (P&L к себестоимости ~$4900/унция)  
   - акции MOEX  
   - BTC  
4. Немного доп. инфы:
   - выплаты с начала (купоны + дивиденды)  
   - выплаты за 30 дней / ср в день или в месяц  
   - годовых (выплаты + P&L)  
   - дней с `InvestMeta.start_date`  
   - опционально: ближайшие выплаты / погашения тела (&lt; 30–90 дней)

Формулы и смысл цифр — как на `invest.html` (капитал по сегодняшним ценам; выплаты в капитал не входят; итог «Заработал» = выплаты + P&L акций/золота/BTC).

## Рекомендуемая реализация

### Вариант A — Apps Script (предпочтительный старт)

Уже есть backend в `apps-script/Code.gs` и листы портфеля.

1. Создать бота у [@BotFather](https://t.me/BotFather) → `BOT_TOKEN`.  
2. Приватный канал: добавить бота **админом** с правом постить; узнать `chat_id` (часто `-100…`).  
   Либо писать в личку: `chat_id` = user id.  
3. В Script Properties сохранить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` (не коммитить в git / Pages).  
4. Функция `sendPortfolioDigest_()`:
   - читает Sheets: `InvestAssets`, `InvestIncome`, `Portfolio`, `BTC`, `Dividends`, `InvestMeta` (+ при необходимости `InvestValue`);  
   - подтягивает котировки теми же источниками, что страница (MOEX, Binance BTC/PAXG, ЦБ USD/RUB, НБРБ/er-api BYN);  
   - считает итоги;  
   - `UrlFetchApp.fetch` → `https://api.telegram.org/bot…/sendMessage`.  
5. Часовой пояс проекта Apps Script: **`(GMT+03:00) Minsk`**.  
6. Триггер: time-driven → Day timer → окно **8am–9am**.  
   У Apps Script нет «ровно 08:00», только часовое окно.

Проверка: один ручной `Run` → сообщение пришло → включить триггер.

### Вариант B — GitHub Actions / Cloudflare Cron

Если нужно **ровно 08:00** Минск: cron `0 5 * * *` (05:00 UTC).  
Секреты: токен бота, chat_id, при необходимости токен Sheets API.  
Логика расчёта та же; данные из Sheets или через уже существующий Web App.

### Вариант C — только вчерашняя точка `InvestValue`

Проще всего, но без живого ± по категориям и без свежих котировок. Для «статуса на утро» слабоват; годится как временный MVP.

## Чего не делать

- Не класть `BOT_TOKEN` в `api.js`, HTML или публичный репозиторий.  
- Не слать пароль страницы (`906090`) и сырые секреты Sheets в Telegram.  
- Не путать **погашение тела** (вернут облигацию/вклад) с **выплатами** (купоны/дивиденды) — в дайджесте это разные строки, как на странице.

## Связь со страницей Invest

Источник правды по смыслу цифр — логика `invest.html` + листы Sheets.  
При внедрении дайджеста либо:

- продублировать расчёт в `Code.gs` (осознанно, держать в синхроне), либо  
- вынести общие формулы позже в один модуль (отдельная задача).

Ежедневная точка капитала уже пишется в лист `InvestValue` (без НЗ, один раз в локальный день) — её можно упоминать в дайджесте как «вчера / сегодня записано $…».
